# configs 目录

本目录存放**运行时生成的配置**，已加入 `.gitignore`，不会提交到仓库。

| 文件 | 说明 |
| --- | --- |
| `server.ini` | FRPS 服务端配置（首次启动后由面板生成） |
| `client.toml` | FRPC 客户端配置 |
| `app_settings.ini` | 面板自身的 Web/守护等设置 |
| `web_auth.ini` | Web 登录账号与口令哈希 |
| `.web_secret` | 会话签名密钥（自动生成，泄露请删除后重启） |
| `*.bak-*` | 修改配置前的自动备份 |

首次启动程序会自动创建以上文件，无需手工准备。
如需恢复默认配置，删除对应文件后重启即可。
