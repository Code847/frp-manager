dashboard_user = admin

版本切换

—

选择要切换的版本后点「切换到所选版本」。 frpc / frps 可分别指定不同版本。

版本来源：bin/ 当前生效文件、bin/versions/ 归档、 以及 temp/frp_<版本>_<平台>/ 里解压出来的官方包。
切换时会自动把原版本归档进 bin/versions/，随时可以切回去。 正在运行的 frpc/frps 会占用文件，请先停止再切换。

手动补充版本：把二进制按 frpc_<平台>_<版本> / frps_<平台>_<版本> 命名放进 bin/versions/， 点「重新扫描本地版本」即可出现在下拉里。

离线导入

支持 .zip / .tar.gz

内网 / 无外网环境：先从能上网的机器下载官方 frp 发布包（含 frpc / frps 二进制），传到本机后在此上传，自动解压并安装到 bin/。

开机启动

—

在各环境下把本程序注册为开机自启（Windows 注册表 / Linux systemd / macOS launchd）。 勾选后本次立即生效，下次开机自动拉起面板；下方两项则在本程序每次启动时自动拉起对应的 frp。 注意：请先完成 frpc / frps 的配置，再勾选「随程序启动」——未配置时即使勾选也会自动跳过，避免启动报错。

守护与告警

进程自愈守护与掉线告警推送的开关统一在此设置；「运行状态 → 进程自愈守护」可查看实时情况。

进程自愈

—

开启后，若 frpc / frps 在「期望运行」状态下意外退出，守护线程每 5 秒检测并自动拉起；连续崩溃超过上限则停止自启并告警，防止雪崩。

定时重启

—

按固定间隔（小时）或每天指定时刻自动重启勾选的 frpc / frps，适合需要定期刷新连接、回收资源的场景；仅重启「正在运行或已登记自愈」的进程，不会擅自拉起未运行的 frp。

掉线告警推送

—

frpc / frps 掉线、自愈失败或启动失败时，通过 Webhook（钉钉 / 飞书 / 企业微信）或邮件通知你。
